Theory Cheat-Sheet

Nullable Variable

A variable A is nullable if it can derive ε in one or more steps.

S → A B
A → ε        ⇒  A is nullable, B is nullable (if B → ε), etc.
B → ε

Rule: A → X₁ X₂ … Xₙ makes A nullable if every Xᵢ is nullable.

Null Production Removal

  1. Find all nullable variables.
  2. For every production, add all combinations where nullable symbols are optionally dropped.
  3. Delete A → ε (unless ε ∈ L(G) and A is start).

Unit Production

A production of the form A → B where both are non-terminals.

Unit pairs: (A, B) such that A ⇒* B using only unit productions.

Unit Production Removal

  1. Compute all unit pairs (A, B).
  2. For each pair, add all non-unit productions of B to A.
  3. Delete all unit productions.

Useless Symbols

A variable is useless if it fails either test:

  • Generating: can derive some terminal string
  • Reachable: has a path from start symbol S

Remove non-generating first, then unreachable.

Why Simplify?

  • Required before converting to CNF / GNF.
  • Removes redundant rules without changing the language.
  • Makes parsing and proofs easier.

Worked Examples

Example A · Null Removal

Before:
S → A B
A → a | ε
B → b | ε

After:
S → A B | A | B
A → a
B → b

Example B · Unit Removal

Before:
S → A | B
A → a
B → b

After:
S → a | b
A → a
B → b

Example C · Useless Removal

Before:
S → abS | abA | abB
A → cd
B → aB
C → dc

After:
S → abS | abA
A → cd

Example D · All Combined

Before:
S → A B | ε
A → B
B → b | ε

After:
S → A B | A | B | b
A → b
B → b
